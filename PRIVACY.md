# Privacy Policy

**Effective Date:** 2026-11-08  
**Project:** MKV to MP4 Converter Pro  
**Author:** FaiazEnd  

---

## 1. Zero Data Collection Commitment
**MKV to MP4 Converter Pro** is a 100% offline desktop application. We believe in absolute privacy:

- **No Telemetry:** We do not track, collect, log, or transmit any user behavior, clicks, or conversion statistics.
- **No Video Data Transmission:** All video remuxing and transcoding takes place locally on your computer's CPU and disk. No media files, filenames, or metadata are ever uploaded to any cloud server or remote service.
- **No Account Required:** You do not need to register, provide an email, or log in to use the software.

---

## 2. Optional Internet Connectivity
The application only accesses the internet in one specific scenario:
- **One-time Portable Engine Download:** If FFmpeg is not found on your system upon first launch, the application prompts to download the official static FFmpeg binaries directly from official release mirrors into your local application data folder. No personal or device data is sent during this download.

---

## 3. Website Privacy
The documentation and landing website hosted via GitHub Pages does not use tracking cookies or marketing pixels. Standard GitHub server logs (such as IP address and user-agent for DDoS prevention and aggregate traffic metrics) are managed by GitHub in accordance with the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement).
